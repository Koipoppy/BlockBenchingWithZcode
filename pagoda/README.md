# 三层宝塔（原版风格佛塔模型）

> 本文件夹是「三层宝塔」的自包含目录：工程、贴图、预览都在这里。共享脚本在 `../tools/`，总索引见 [../README.md](../README.md)。

Blockbench 工程：石砌台基上的三层佛塔——灰泥抹墙配木构架（角柱、阑额），每层出深色瓦檐，
顶上金色塔刹（相轮 + 宝珠收尖），正面开红门。44 个方块，64×64 贴图内嵌，门朝 -Z（北），
Blockbench 打开工程第一眼就能看到入口。

| 文件 | 说明 |
|---|---|
| `pagoda.bbmodel` | Blockbench 工程（可直接打开） |
| `pagoda.png` | 同一张贴图，单独导出 |
| `preview_pagoda.png` / `_front.png` / `_top.png` | 3/4、正面、俯视三个角度的离线渲染预览 |
| `../tools/build_pagoda.py` | 一键生成脚本（贴图 + 几何 + 写出 `.bbmodel`） |

## 设计要点（摘自 build_pagoda.py 的说明）

- 三层"灰泥 + 木构"塔身，层层收分，每层出**阶梯状深瓦檐**；
- 石砌台基，金色**塔刹**带相轮环与宝珠；
- 配色全部取自原版有的材质观感：石灰岩灰、灰泥墙、深胡桃木、石板蓝瓦、金；
- 该模型自己的约定：UV 矩形按 **crop 模式**采样——面按尺寸取矩形左上角的 w×h 像素，
  所以任何一层的面都是 1:1 纹素密度；每个矩形从原点画成无缝平铺，叠檐因此能对齐。

## 重新生成 / 改动

```bash
python ../tools/build_pagoda.py     # 重新生成 bbmodel + png
```

预览图用 `../tools/preview_bbmodel.py` 渲染（3/4、正面、俯视三个角度）。
调色板和几何都在 `build_pagoda.py` 顶部与 `build_tree()` 里。
