# 地狱飞龙（hell_dragon）v3

巨型西方地狱飞龙 v6，Boss 级游戏实体模型。全程经 headless MCP（`blockbench-mcp-headless` 1.9.1）
建模、校验、渲染、导出；生成脚本 `property/tools/build_hell_dragon.py`，重跑即可复现。

## v3/v4 重做（用户验收意见驱动）

- **颈/尾/角/腿全链式**：每节是沿延伸方向的 pitched 长方体（element rx 绕后端面中心
  旋转，累计角递推）——颈 4 节 22°→60° S 形上扬，尾 6 节 8°→36° 下垂渐细，
  龙角 5 节仰角 80°→8° 后掠弧（截面 2.2→1.2 渐细），腿股-胫-足-3 爪收折
  （股 35-40°/胫 65-70°/足 15-18°，飞行姿向后收）
- **蹼状翼**：4 根指骨从腕部扇形辐射（element ry 旋转，3°/22°/42°/62°），
  指间蹼膜为沿平分角的旋转薄板条（每楔 2 条、外条短窄 → 阶梯扇形收口），
  内翼膜三条板条前缘藏臂下；板条交替厚度防共面闪烁
- **躯干瘦身**（v4）：胸 12 宽/16 高（原 16×20），髋 10×14，腹甲只悬 9 格——
  体量读作猛禽躯干而非木桶

## 规格

- 843 个元素 = 93 结构方块 + 764 张零厚度翼膜面片（1.5 格栅格化，双面），26 根骨骼（颈 5 节，末节埋入头颅）；绑定姿态为飞行收折姿
- 尺寸因子 S=1.3：翼展 187 单位（≈11.7 格）、体长 204 单位（≈12.7 格）
- 翼 = 蝙蝠辐条+面片：**全骨架 1.5×1.5 细辐条**（肱骨/前臂链式埋接、3 内辐条、4 指骨，肘部折角连续）+ 零厚度膜面（内外楔形、后缘斜扫不填满），导出按零厚度 cube 保留；贴图 256×256 程序化像素画：叠瓦鳞、低对比腹甲、分叉余烬血脉翼膜、
  黑曜石角爪、骨刺余烬尖、矩形边缘 1px 假 AO
- 格式 `free`（Generic Model），显式逐面 UV（1 uv 单位 = 1 px）

## 校验（bbmodel_validate）

errors = 0；floating / degenerate / mirror / outliner 全绿。
29 条 interpenetration 警告逐对核对，全部为**设计内嵌合**（镜像后成对）：

- 颈/尾链节交界楔形（pitched 链节的几何必然，≈(h/2)·sinΔθ）
- 胸/髋与颈根尾根、指骨根与腕部前臂、翼膜条与臂骨的嵌合（同理于肢体根埋入躯干）

## 设计说明

- 巨口：吻底与颌顶间 5 格开口，喉部余烬发光，四獠牙（上二下二）
- 翼膜栅格化：_IN_POLY/_WEDGE_SPECS 多边形 → 1.5 格零厚度面片（最大连通分量），
  UV 世界锁定（血脉连续）；validate 用 free_elements 放行面片
- 头颅沿颈链顶端轴对齐架设，头基座与颈 4 同角（60°）楔接
- 尾矛三叉随末节 -36° 方向 pitch，五件同组免穿插警告
- 镜像件：`_fl/_bl` 后缀（腿）与 `_l` 后缀统一由 `_mirror_name()` 处理
  （v2 教训：`endswith("_l")` 匹配不到 `_fl`，右腿整列丢失）
