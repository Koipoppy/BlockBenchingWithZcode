# 精致鸟居（明神鸟居模型）

> 本文件夹是「精致鸟居」的自包含目录：工程、贴图、预览都在这里。共享脚本在 `../tools/`，总索引见 [../README.md](../README.md)。

Blockbench 工程：明神鸟居（神社牌坊）——朱漆双柱**内倾 5°**，三段**反曲笠木**（端头 +8° 上翘拟反り），
笠木下岛木、中段贯（nuki）穿透双柱并外挑、贯与岛木之间嵌**额束**（深漆底 + 金色小鸟居图形），
笠木两端**金色拟宝珠**收顶；贯下挂**注连绳**（三段下垂 0.6）与两串**纸垂**（三折之字形），
柱脚双层**台石**，一条石板小径从鸟居下穿过。32 个方块，128×128 贴图内嵌，正面朝 -Z（北），
Blockbench 打开工程第一眼就是正脸。

| 文件 | 说明 |
|---|---|
| `torii.bbmodel` | Blockbench 工程（可直接打开） |
| `torii.png` | 同一张贴图，单独导出 |
| `preview_torii.png` / `_front.png` / `_detail.png` | 3/4、正面、绳结额束特写三个角度的离线渲染预览 |
| `../tools/build_torii.py` | 一键生成脚本（贴图 + 几何 + 写出 `.bbmodel`） |

## 设计要点（摘自 build_torii.py 的说明）

- **柱内倾**：绕柱脚轴心 (±11, 3, 0) 转 rz ±5°（绕 +Z 转 +5° 时 +Y 倒向 -X，所以东柱 +5、西柱 -5）；
  柱顶（y≈32.9）插进岛木（y 32..34）里，不留缝；
- **反曲笠木**：中段平（x ±11，y 34..37），两端段 x 10.75..16 绕 (±11, 35.5, 0) 转 ±8°——
  端段内端埋进中段 0.25 避免接缝楔口，外端升到 y≈37.7，拟宝珠（三段金方块）底面
  嵌进斜梁顶 0.5~0.9，外缘 16.1 恰好收在梁端 16.16 之内；
- **额束**：4×4 的脸太小，任何金边框都会反客为主（第一版就渲染成"金块两根黑条"），
  最终是深漆占主体 + 无边框的金色小鸟居图形（横梁 + 双腿，左右对称可南北共用矩形）；
- **纸垂**：第一版两串段宽 3、中心距 3.4，糊成一团；改为段宽 2.2、中心距 4.2、
  同向错位 1.0（真实纸垂本来就同向折叠），三段各 1.6 高挂在绳中段下方；
- 配色：朱漆（带风化斑点）、金色拟宝珠、稻草绳、白纸垂、石灰岩台石小径——全部取自原版有的材质观感；
- UV 共享图集与 cottage 同约定：面按 (材质, 宽, 高) 取矩形，画法全部噪点/左右对称。
